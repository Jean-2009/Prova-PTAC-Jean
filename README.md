# Mural de Avisos 🌿

Aplicação web em React que funciona como um mural digital de avisos.
É possível listar, publicar, editar e excluir avisos (CRUD completo)
consumindo uma API REST.

## Como instalar e rodar

    npm install
    npm run dev

Depois abra http://localhost:5173 no navegador.

## API usada

https://jsonplaceholder.typicode.com/posts
